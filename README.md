# 📘 Guía técnica: Cómo descargar Roblox

# 📖 Introducción
Roblox es una plataforma de videojuegos en línea que permite a los usuarios crear, compartir y jugar experiencias interactivas.  
Esta guía explica cómo descargar e instalar Roblox en tu computadora de forma sencilla y organizada.  

---

# 🔎 Requisitos previos
- Conexión a internet estable.  
- Una cuenta en Roblox.  
- Sistema operativo compatible: Windows, macOS o dispositivos móviles.  

---

# 📥 Pasos de instalación
1. Accede al sitio oficial de Roblox: [https://www.roblox.com](https://www.roblox.com).  
2. Inicia sesión en tu cuenta o crea una nueva.  
3. Selecciona un juego y haz clic en **Play**.  
4. Descarga el instalador cuando aparezca el mensaje.  
5. Ejecuta el archivo descargado y sigue las instrucciones.  
6. Verifica la instalación abriendo un juego desde la página.  

---

# 🚀 Ejecutar la aplicacion
Puedes abrir la aplicación dándole doble clic al acceso rápido que sé en cuenta en el repositorio, pero si por alguna razón no te aparece también lo puedes abrir desde PowerShell.
Ejemplo de cómo ejecutar el instalador en Windows:  

```powershell
Start-Process "RobloxPlayerLauncher.exe"
```
